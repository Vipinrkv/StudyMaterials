# MASTER BIBLIOGRAPHY & ACADEMIC REFERENCES

This library is grounded in foundational computer science literature, authoritative textbooks, peer-reviewed ACM/IEEE publications, and official engineering specifications. Every citation is verified against established editions.

---

## 📖 Foundational Computer Science & Hardware Architecture

1. **Stallings, William.** *Computer Organization and Architecture: Designing for Performance.* 11th Edition, Pearson, 2018. ISBN: 978-0134772806.
   - *Core coverage:* Von Neumann architecture, CPU pipelines, cache memory hierarchy, bus standards, superscalar processors.
2. **Patterson, David A., and John L. Hennessy.** *Computer Organization and Design: The Hardware/Software Interface (RISC-V Edition).* Morgan Kaufmann, 2017. ISBN: 978-0128122754.
   - *Core coverage:* Instruction set architectures, pipelining hazards, virtual memory, parallel processors from client to cloud.
3. **Petzold, Charles.** *Code: The Hidden Language of Computer Hardware and Software.* 2nd Edition, Microsoft Press, 2022. ISBN: 978-0137909100.
   - *Core coverage:* Intuitive progression from flashlights and relays to logic gates, RAM, and assembly language.

---

## 💻 Programming Languages & Foundations

4. **Kernighan, Brian W., and Dennis M. Ritchie.** *The C Programming Language.* 2nd Edition (ANSI C), Prentice Hall, 1988. ISBN: 978-0131103627.
   - *Core coverage:* Syntax, data types, pointer arithmetic, memory allocation, system calls.
5. **Lutz, Mark.** *Learning Python.* 5th Edition, O'Reilly Media, 2013. ISBN: 978-1449355730.
   - *Core coverage:* Python object types, dynamic typing, scoping, generators, OOP in Python.

---

## 🧮 Data Structures, Algorithms & Discrete Mathematics

6. **Cormen, Thomas H., Charles E. Leiserson, Ronald L. Rivest, and Clifford Stein (CLRS).** *Introduction to Algorithms.* 4th Edition, MIT Press, 2022. ISBN: 978-0262046305.
   - *Core coverage:* Asymptotic analysis, divide-and-conquer, dynamic programming, greedy algorithms, graph traversal, NP-completeness.
7. **Rosen, Kenneth H.** *Discrete Mathematics and Its Applications.* 8th Edition, McGraw-Hill, 2018. ISBN: 978-1259676512.
   - *Core coverage:* Propositional logic, set theory, relations, combinatorics, graph theory, Boolean algebra.
8. **Sedgewick, Robert, and Kevin Wayne.** *Algorithms.* 4th Edition, Addison-Wesley, 2011. ISBN: 978-0321573513.
   - *Core coverage:* Priority queues, balanced search trees (Red-Black), graph algorithms, string processing.

## 🗄️ Database Systems & Data Engineering

9. **Silberschatz, Abraham, Henry F. Korth, and S. Sudarshan.** *Database System Concepts.* 7th Edition, McGraw-Hill, 2019. ISBN: 978-0078022159.
   - *Core coverage:* Relational model, SQL, normalization (1NF-BCNF), B+ trees, ACID transactions, concurrency control (2PL, MVCC), recovery.
10. **Elmasri, Ramez, and Shamkant B. Navathe.** *Fundamentals of Database Systems.* 7th Edition, Pearson, 2015. ISBN: 978-0133970777.
    - *Core coverage:* ER and EER modeling, query optimization, physical database design.
11. **Kleppmann, Martin.** *Designing Data-Intensive Applications: The Big Ideas Behind Reliable, Scalable, and Maintainable Systems.* O'Reilly Media, 2017. ISBN: 978-1449373320.
    - *Core coverage:* Replication, partitioning/sharding, transactions, batch and stream processing, consensus.

## ⚙️ Operating Systems & Systems Programming

12. **Silberschatz, Abraham, Peter B. Galvin, and Greg Gagne.** *Operating System Concepts.* 10th Edition, Wiley, 2018. ISBN: 978-1119456339.
    - *Core coverage:* Processes, threads, CPU scheduling, synchronization primitives, deadlocks, virtual memory, file systems.
13. **Arpaci-Dusseau, Remzi H., and Andrea C. Arpaci-Dusseau.** *Operating Systems: Three Easy Pieces (OSTEP).* Arpaci-Dusseau Books, 2018 (v1.00). Free Online: https://pages.cs.wisc.edu/~remzi/OSTEP/
    - *Core coverage:* Virtualization (CPU, memory), concurrency (threads, locks, condition variables, semaphores), persistence (disks, file systems).
14. **Love, Robert.** *Linux Kernel Development.* 3rd Edition, Addison-Wesley, 2010. ISBN: 978-0672329463.
    - *Core coverage:* Process management, kernel scheduler, interrupts, memory management, VFS.

---

## 🌐 Computer Networks & Distributed Systems

15. **Kurose, James F., and Keith W. Ross.** *Computer Networking: A Top-Down Approach.* 8th Edition, Pearson, 2020. ISBN: 978-0136681557.
    - *Core coverage:* Application layer (HTTP, DNS), transport layer (TCP flow/congestion control, UDP), network layer (IP, BGP/OSPF routing), link layer.
16. **Tanenbaum, Andrew S., and Maarten van Steen.** *Distributed Systems: Principles and Paradigms.* 3rd Edition, CreateSpace, 2017. ISBN: 978-1543057386.
    - *Core coverage:* Architectures, processes, communication (RPC, message-oriented), naming, synchronization (clock synchronization, mutual exclusion), consistency and replication, fault tolerance.

## 📐 Theoretical Computer Science & Compilers

17. **Hopcroft, John E., Rajeev Motwani, and Jeffrey D. Ullman.** *Introduction to Automata Theory, Languages, and Computation.* 3rd Edition, Pearson, 2006. ISBN: 978-0321455369.
    - *Core coverage:* Finite automata, regular expressions, context-free grammars, pushdown automata, Turing machines, decidability.
18. **Aho, Alfred V., Monica S. Lam, Ravi Sethi, and Jeffrey D. Ullman (Dragon Book).** *Compilers: Principles, Techniques, and Tools.* 2nd Edition, Pearson, 2006. ISBN: 978-0321486813.
    - *Core coverage:* Lexical analysis, syntax analysis (LL/LR), syntax-directed translation, intermediate code generation, optimization, target code generation.

## 🏗️ Software Engineering, Clean Code & Architecture

19. **Sommerville, Ian.** *Software Engineering.* 10th Edition, Pearson, 2015. ISBN: 978-0133943030.
    - *Core coverage:* Requirements engineering, system modeling, architectural design, agile development, software testing, quality management.
20. **Martin, Robert C.** *Clean Code: A Handbook of Agile Software Craftsmanship.* Prentice Hall, 2008. ISBN: 978-0132350884.
    - *Core coverage:* Meaningful names, small functions, error handling, unit testing, SOLID principles.
21. **Gamma, Erich, Richard Helm, Ralph Johnson, and John Vlissides (GoF).** *Design Patterns: Elements of Reusable Object-Oriented Software.* Addison-Wesley, 1994. ISBN: 978-0201633610.
    - *Core coverage:* Creational, Structural, and Behavioral patterns.
22. **Bass, Len, Paul Clements, and Rick Kazman.** *Software Architecture in Practice.* 4th Edition, Addison-Wesley, 2021. ISBN: 978-0136886006.
    - *Core coverage:* Quality attributes (availability, modifiability, performance, security), architectural tactics and patterns.

## 🤖 Artificial Intelligence, Machine Learning & Modern Systems

23. **Russell, Stuart, and Peter Norvig.** *Artificial Intelligence: A Modern Approach.* 4th Edition, Pearson, 2020. ISBN: 978-0134610993.
    - *Core coverage:* Problem-solving agents, search algorithms, knowledge representation, probabilistic reasoning, machine learning, reinforcement learning.
24. **Goodfellow, Ian, Yoshua Bengio, and Aaron Courville.** *Deep Learning.* MIT Press, 2016. ISBN: 978-0262035613.
    - *Core coverage:* Linear algebra, probability, deep feedforward networks, regularization, optimization, convolutional networks, sequence modeling.
